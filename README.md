## The joke

> Our standup is nine people reading their to-do lists out loud to a tenth person who is also reading a to-do list, but with more confidence.

## How it runs

`main.py` (Python standard library only) writes the joke to the entry
output path — `ENTRY_OUTPUT` if set, else `OUTPUT_DIR`/`MAKEFUN_OUTPUT_DIR`
joined with `entry.txt`, else `/output/entry.txt` — and marks the file
readable (mode 0644). `entry.txt` holds the same line.
